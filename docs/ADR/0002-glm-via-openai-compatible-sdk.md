# ADR-0002. GLM через OpenAI-совместимый SDK; провайдер абстрагирован

- Статус: принят (шаг 1)
- Дата: 2026-09-04

## Контекст
Мозг — GLM-4.6 (z.ai, OpenAI-совместимый `/chat/completions`), зрение — GLM-4.6V, фон —
GLM-4.5-Air. Провайдер может смениться (цена, лимиты, локальные модели), а требования — retry,
fallback, учёт стоимости, DLP, аудит — относятся к любому.

## Решение
Единственная точка выхода к моделям — `aegis.platform.gateway.ModelGateway`:

- клиент — `openai.AsyncOpenAI` (`GLM_BASE_URL`), `max_retries=0`: политика повтором наша, иначе
  нельзя корректно переключиться на fallback и записать каждый attempt;
- каталог ролей (`brain | vision | fast | embed`) с ценами — `gateway/models.py`; имена моделей
  переопределяются env-ом (`MODEL_BRAIN`, …) без правки кода;
- retry с экспоненциальным backoff только для retryable-ошибок (408/409/425/429/5xx, timeout,
  connection error), затем — переход на fallback;
- `extra_body={"thinking": {...}}` передаётся только primary и только ролям с `supports_thinking`;
- каждый attempt пишется в `platform.llm_calls` (токены, стоимость, латентность, ok/error, attempt,
  провайдер) — это и бюджет, и наблюдаемость, и материал для будущих дистилляций.

## Последствия
- (+) Смена провайдера = правка каталога и ценника; инструменты и логика агента не трогаются.
- (+) Локальные/дешёвые модели подключаются как ещё один «клиент» в `_providers()`.
- (+) Деградация по бюджету встроена в точку выхода: забыть про неё на уровне инструмента нельзя.
- (−) Стоимость считается по каталогу, а не по биллингу провайдера — цены синхронизируем вручную
  (задача в RUNBOOK).
- (−) `thinking` — нестандартный параметр: на fallback он отключается, поведение там беднее.
