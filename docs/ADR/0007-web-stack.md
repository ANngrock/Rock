# ADR-0007. Web: self-hosted SearXNG + trafilatura, встроенный поиск GLM — резерв

- Статус: принят (шаг 1)
- Дата: 2026-09-04

## Контекст
«Ищи в интернете» — самая частая бытовая команда. Платные поисковые API (Brave/Serper/Google)
требуют ключей, стоят денег и уносят запросы наружу; у GLM есть встроенный поиск, но он
непрозрачен: его нельзя ни закэшировать, ни отфильтровать, ни посчитать его стоимость.

## Решение
- `WebSearch` ходит в собственный SearXNG (`/search?format=json`); json включён в
  `deploy/searxng/settings.yml`, rate limiter выключен (инстанс не публичный);
- `WebFetch` — `httpx` + `trafilatura` (`favor_recall=True`), текст + заголовок; если статья не
  распозналась (SPA, заглушка) — отдаём очищенный видимый текст, а не пустой ответ;
- редиректы шагаем сами (до 3 хопов), и каждый hop проходит SSRF-фильтр (`aegis.web.net`):
  схемы только http/https, резолв имени, запрет private / loopback / link-local / multicast /
  reserved. Иначе «прочитай ссылку» превращается в «прочитай 169.254.169.254/latest/meta-data/ и
  внутренние сервисы хоста»;
- всё внешнее возвращается модели в `<untrusted source="...">...</untrusted>`, причём закрывающий
  тег из тела вырезается, чтобы страница не могла «выйти» из контейнера раньше времени;
- отказ не маскируется: инструмент возвращает `ПОИСК НЕДОСТУПЕН: ...`, и модель обязана сказать это
  владельцу, а не выдумать результаты (правило 1 промпта).

## Последствия
- (+) Приватность: запросы не уходят третьим сторонам; поведение повторяемо (свой инстанс).
- (+) Стоимость предсказуема: 0 за запрос, независимо от тарифов провайдера.
- (−) SearXNG требует обслуживания (качество выдачи, движки) — это часть «платформы», шаг 11.
- (−) Любой будущий браузер-агент (шаг 7) обязан переиспользовать `aegis.web.net`, а не изобретать
  свой путь в сеть.
